Cognex to Acquire RealSense for $500 Million, Pushing Into Robot Vision

The Israeli-founded, Intel-spun depth-camera maker joins a machine-vision giant as robots need to see in 3D.
Sept. 22, 2026 · Cognex & RealSense press release

Cognex Corporation, a machine-vision company, has agreed to acquire RealSense for about $500 million in cash. RealSense makes depth-sensing cameras that let robots judge distance and shape in three dimensions, and its technology already supports robot arms, mobile robots, four-legged robots and humanoids.

RealSense was founded inside Intel in 2014 and spun out as an independent company only in 2025. Cognex says RealSense's revenue is set to grow more than 50 percent this year, and it values the robotic-perception market the deal opens up at about $600 million today, growing toward $1.6 billion by 2030.

The deal is expected to close in the fourth quarter of 2026. Before then, RealSense will spin off its separate facial-authentication product line so the remaining business can focus only on robotic perception.

Learn: 2D vision vs. depth sensing

Ordinary machine vision reads a flat, 2D image, good for reading labels or checking a part's shape. A depth camera adds a third dimension, distance, so a robot can tell how far away an object is and navigate around it. This is essential for a robot that moves through open space rather than staying bolted to one spot on a line.

Qualcomm to Buy PickNik, Bringing Robotics Software to Arduino Boards

Sept. 23, 2026 · ROSCon, Toronto

Qualcomm has agreed to acquire PickNik Robotics, the company that maintains MoveIt, a widely used open-source robot manipulation framework. Qualcomm says MoveIt will stay open-source and will gain closer support on its Dragonwing robotics chips.

The first move into Arduino hardware is the Arduino VENTUNO Q board, which is built on Qualcomm's Dragonwing IQ-8275 processor and pairs an AI chip rated at up to 40 TOPS with a real-time microcontroller. That combination lets one board handle both AI perception and precise, time-critical motor control.

Learn: what is MoveIt, and what is a TOPS?

MoveIt is software that plans how a robot arm should move without hitting itself or its surroundings, built on ROS (Robot Operating System), the standard toolkit most robotics students already use. TOPS (trillion operations per second) measures how fast an AI chip can compute; more TOPS means the chip can run bigger perception models on the robot itself, instead of sending data to a distant server.

Open-Source Robotics

NVIDIA Launches Isaac ROS 5.0 With AI "Agent Skills"

Sept. 21–22, 2026 · ROSCon, Toronto

NVIDIA released Isaac ROS 5.0, a free, GPU-accelerated add-on to ROS that NVIDIA says reaches nearly 1.3 million ROS users. The new version adds "agent skills," reusable step-by-step routines that an AI coding assistant can follow to set up perception or a pick-and-place task, instead of a person writing that setup code by hand.

It also moves onto the newest long-term-support version of ROS 2 and adds a way to share GPU memory more efficiently between different parts of a robot's software.

Learn: what is ROS?

ROS is not an operating system in the Windows or Linux sense; it is a common set of tools and libraries that let different parts of a robot, cameras, arms, wheels, planning software, talk to each other in a standard way. Almost every robotics lab and most student robotics projects build on it, which is why a free upgrade like this reaches so many developers at once.
